# 改动说明

对课程网站 <https://cinger007.github.io/vis/> 的重构说明。

**做法是「内容迁移式重构」**：把旧站的 27 个小节、441 个内容块、27 个交互演示无损搬进新的内容层，然后在干净的外壳上重建导航、样式与多语言机制，并补上原来没有的学习功能。教学内容一行未改（个别旧站遗留错误见 §4）。

**内容零损失由构建期门禁机械保证**，不靠人工核对：逐小节比对旧站 DOM 与新内容层的块集合（中英各一遍），并独立计数 `<pre>` / `<ul>` / `<ol>` / `<table>` / `<figure>` / `<img>` / 演示挂载点。任一不符，构建直接中断。

## 2. 结构性问题：为什么要重建外壳而不是「叠加功能」

以下几点是旧站的结构造成的，加功能无法解决：

**2.1 双语靠复制 DOM 节点实现。** 每个段落都是成对出现，一份 `hidden`：

```html
<p data-lang="zh-CN">本章采用……含 80 条记录。</p>
<p data-lang="en-US" hidden>This chapter uses……</p>
```

`<li>` 更严重——中英条目**交替共存于同一个 `<ul>`** 里（顶部导航就是这样），对屏幕阅读器是语义污染。这是单页 HTML 达 88 KB 的直接原因。

**2.2 两套互相打架的多语言机制并存。** 一部分节点用 `data-i18n="key"` 查 283 键字典，其余用 `data-lang` 双节点；`i18n.js` 在根目录和 `supplementary/` 各存一份（28 KB / 24 KB，已无法互校）。

**2.3 五章是五份复制粘贴的副本。** 5 份独立样式表（体积已各不相同，说明早已各自改跑偏）、5 份 `lesson.js`（各自内嵌本章演示，零共享）。

→ **任何跨章节功能都要在 5 个副本里各改一遍，且每个改动都要在两种语言机制里各做一次。** 所以「加功能」在这套结构上并不便宜；而正确性目标（内容更清晰）本身就是结构问题。

**改动后的机制**：内容层里双语同源（同一文件内的成对字段），构建期展开为**纯单语页面**——中文站部署在根目录（延续旧站 `/lesson-01/` 等 URL，学生书签不失效），英文站镜像到 `/en/`，语言切换就是一个普通 `<a href>`。页面里只有一种语言、没有隐藏节点、没有运行时字典，双语也不再可能漂移。

### 3.9 知识地图改为「左球右栏」并加入章节筛选

原来的地球仪占满整宽（球体居中、右侧只有一条细图例），球体直径约 480px，左右留白很多；右侧那条图例信息量也太低。现在改成左右分栏：

| 改动 | 说明 |
|---|---|
| **布局** | 左栏为地球仪（实测 634px），右栏为内容面板（586px），`1.04fr : 0.96fr`；≤1080px 堆叠为上下 |
| **右栏内容** | 顶部是**章节筛选**（「全部章节 27」+ 五章各一行，带色点与该章小节数），下面是**该章的小节芯片**，再下面是操作提示 |
| **筛选联动** | 点某一章：其它章的点在地球仪上淡到 16% 并缩小、该章转到球的正面（按该章平均经度求目标偏航角，取最短转向）、右侧只留该章的小节芯片、自转暂停（便于看清）；点「全部章节」恢复自转与全量显示 |
| **无障碍改善** | 27 个小节现在是右栏里**可见的真实链接**（共 27 条，筛选只切换 `hidden`，不移出 DOM），键盘与读屏可以直接走这条路径。上一版为此额外放了一份 `sr-only` 列表，现在不需要了 |

实测：点「色彩专题」→ 可见芯片从 27 变为 8、球面重绘、筛选按钮 `aria-pressed` 正确；点「全部章节」→ 恢复 27；点筛选后的第一个芯片 → 精确跳到 `/lesson-03/#3-1` 且侧栏高亮跟上。

顺带把 `.sr-only`（已无引用）与 `demos.css` 里 6 条确认为零引用的规则删掉 —— CSS 回到 59.7 KB，重新落进 60 KB 预算内。

| # | 改动 | 作用 / 原因 |
|---|---|---|

### 3.6 第三轮修订（据实际试用反馈）

| # | 问题 | 原因与修法 |
|---|---|---|
| 29 | **点击后紫色高亮框卡住不动** | 滚动定位里用一个 `Set` 记录「已标记过的小节」以减少 DOM 写入，实际后果是每个小节只标记一次、之后无论是滚动还是点击都不再更新，高亮会永久停在上一个小节。改为只记录「上一次的值」，并新增：**点击侧栏/目录时立即跟随**（不等滚动结束）、侧栏加一条**会滑动的指示条**（`translateY` 过渡）、hash 同步。实测五个方向（初始 / 点下 / 点上 / 滚到底 / 滚回顶）全部正确 |
| 30 | **首页标题太长、字太多** | 标题改为 **6 字「从数据到图表」居中**（78px）；首屏只留三行文字（标题 / 一行数据 / 一行图注），删掉原来的长引导段、四项 kicker 与 27 项概念跑马灯；数字改为一行内联的滚动计数 |
| 31 | **图表要主动点才切换** | 改为**默认自动播放**（每 3.2s 换一种图形），并提供**暂停按钮**与四个可点击圆点。原先「系统开启减少动效就不自动播放」的处理是过度保守——图表变形属于教学内容而非装饰，停播会把知识点一起丢掉；现改为用户显式控制（暂停 / 专注模式）。背景色带的流动仍严格遵循该偏好 |
| 32 | **知识地图乱、连线杂乱、尺寸不合适** | 原来用 SVG 分列图 + 8 条常驻跨章连线，问题是：小字**无法随字号缩放**、标签容易碰撞、常驻连线一眼看去杂乱。改为 **HTML 章节轨道 + 芯片**：每章一行、27 个芯片自动换行；芯片是**真实 `<a>` 链接**（可键盘访问、可随字号缩放、窄屏自动堆叠）；跨章关联改为**悬停/聚焦时才亮出**（关联项高亮、其余淡出），静止状态下画面是干净的 |
| 33 | **新增可调节字体大小** | 顶栏加入字号控件（**90% / 100% / 112% / 125%** 四档，`localStorage` 持久化，到达上下限时按钮自动禁用）。实现为 `--fs-scale` 乘以正文/代码/标题/芯片等字号（新增 `type-scale.css` 覆盖层），并随缩放微调行距，放大时不会拥挤 |
| 34 | **整体动效偏少** | 新增：跨文档 **View Transitions**（站内跳转淡入淡出）、章节卡悬停**渐变描边**、主按钮**掠光**、**返回顶部**按钮（滚动 700px 后浮现）、进度环**首次入视口时描边生长**、章节轨道与芯片的**错落入场** |

**第二轮的问题也一并在这一轮修掉**：主视觉面板的边框/背景样式在替换 Hero 区块时被整段删掉（图表失去了容器），已补回；移动端顶栏因新增字号控件而挤出视口、章节轨道被挤成 20px 窄缝（媒体查询写在了 `components.css` 之前，同优先级下不生效），两处都已修正。

| # | 改动 | 作用 / 依据 |

原来一次性铺出 27 个小节芯片，用户反馈「太繁琐、不好看」。现在：

- 与球体联动：点开某章时球体转到该章正面、其它章的点淡出。

### 6.6 去掉几处「模板感」特征

参照前端设计规范里点名的几类通用套路，逐条清掉：

### 6.7 新增动效（共 7 处）

按规范「动效要回答操作、说明变化，而不是给每个区块来一次遍地淡入」的原则：

2. **章节展开：小节逐行错落滑入**（回答点击）
3. **章节行圆点展开时脉动一次**（说明状态变了）
4. **卡片悬停：顶边一道掠光扫过**（比单纯上浮更明确）
5. **搜索结果逐条错落出现**（打开面板与每次输入都有反馈）
6. **小节标题的遮罩揭示**（滚动驱动，`animation-timeline: view()`；不支持时退化为播放一次）
7. **章节页右栏三块卡片依次滑入**

再加上已有的：玻璃入口按钮的呼吸光晕、进度环首次入视口时描边生长、数字滚动累加、Tab 下划线滑轨与面板交叉淡入、跨文档 View Transitions。

### 6.8 踩到并修掉的一个 bug：Canvas 颜色

银河第一版是**一整块空白**。原因有两层，都属于「Canvas 不认 CSS」：

1. `ctx.strokeStyle = 'var(--border-strong)'` —— Canvas 不解析 CSS 变量，赋值静默失效；
2. 我原来的 `hexA()` 只处理十六进制，遇到 `rgba(143, 174, 159, 0.09)` 会被拼成 `rgba(143, 174, 159, 0.09, 0)`（五个分量）→ `addColorStop` 抛 `SyntaxError` → 整帧绘制在银河带那一步中断，画布全空。

第 2 点还很隐蔽：异常发生在 `requestAnimationFrame` 回调里，`init()` 本身不报错，光看控制台也未必注意到。修法是抽出 `src/scripts/color.js`（`cssVar` / `parseColor` / `withAlpha` / `withVar`），`sky.js` 与 `globe.js` 共用；顺手把 `globe.js` 里残留的旧紫色硬编码（`rgba(120,120,240,…)`）也换成令牌读值。

## 7. 第七轮：流动的银河 · 翻书式过渡 · 动效开关

### 7.1 银河从「静态星空」改成真正流动的银河

上一版有星带、尘埃与流星，但整体还是「静止的星空」。这一版加了两层运动与一层实体：

| 新增 | 做法 |
|---|---|
| **沿带流动** | 每颗星有自己的流动速度，位置随时间沿带轴前移；到带的两端按距离淡出再绕回，所以看不出接缝 |
| **亮度行波** | 一道亮度波沿带轴传播（`sin(u * 7.5 - t * 0.0004)`），星点是「一片被光扫过」而不是各自闪烁 —— 这是流动感最直接的来源 |
| **行星** | 4 颗大小不一的球体点缀在带上：本体带偏心高光（像被同一束光照着）、外圈柔光晕、最大那颗带一圈环；亮度按各自频率缓慢脉动，并沿带缓慢漂移 —— 就是「点缀的行星在闪」 |

行星颜色取自同一套令牌（香槟 / 灰玉 / 玫瑰石英 / 岩板），不引入新颜色。

### 7.2 课程总览页：翻书式分区过渡

每一块内容（页头、知识地图、章节、使用方式、关于、结尾）都从上方微微掀起、带透视缩短，落到正常位置，过程中顶边压出一道翻页阴影：

- 用 **滚动驱动动画**（`animation-timeline: view()` + `animation-range: entry`），速度完全跟着滚轮/手指，不会自己播；容器加 `perspective: 1500px`；
- 顶边的翻页阴影随入场淡出，落位后完全消失（实测最终 `transform` 为单位矩阵、阴影 0）；
- 另加**轻吸附**（`scroll-snap-type: y proximity`）：接近段落边界时帮一把，但不强制，不会打断阅读。

### 7.3 新增「动效」开关（重要）

这台机器的系统偏好一直是「减少动效」，所以此前所有动画都被按规范关掉了 —— 用户看不到刚做的东西。现在顶栏加了一个**动效开关**（星芒图标）：

- 没选过时**跟随系统偏好**（尊重默认）；
- 点一下即**显式选择**并记在本地，之后一直生效；
- 实现上把原先散落在各处的 `@media (prefers-reduced-motion: reduce)` 硬关闭，统一改成 `html[data-motion="off"]` 的可覆盖规则；JS 侧的 `calm()` 也改为读这个属性；
- 开关一打开，银河的流动/行波/行星、球体自转、指针拖尾、翻书过渡会立刻恢复（为了让画面立即重绘，开关会主动触发一次 resize）。

### 7.4 两处顺手的改进

| 改进 | 说明 |
|---|---|
| **悬停章节行 → 球体预览** | 鼠标移到某一行上，球面上非该章的点会淡出（但不会打开小节、不改变选中状态）；移开即恢复。让右侧列表与左侧球体产生联系 |
| **滚动进度条常驻** | 原先只有门户页有，现在所有页面（含章节页、术语表）顶栏下方都有一条细进度条 |

## 8. 第八轮：旋臂星系 · 一屏一节 · 表格可读性

### 8.1 银河重做成「旋臂星系」

上一版是「一条星带绕屏幕中心转」，那不是银河的转法。真实的旋臂星系是**盘面绕自己的银心整体旋转**，而且几乎不正对着我们看。这一版按业界常用的旋臂星系生成器参数重写：

```
半径 r   = pow(rand, 1.7) * R              越靠银心越密
旋臂编号 = i % 3
角度 a   = 编号/3 * 2π + r * 2.42          旋臂是绕出来的
散布     = pow(rand, 1.6) * r * 0.17       外圈更松散
```

旋转的关键是**刚性**：所有星共用同一个角速度，旋臂因此不会被剪切打散；再叠加每颗星自己的小幅「本轮摆动」与闪烁，于是整片星系在缓慢转动而旋臂结构始终清晰。盘面按 -0.30 rad 倾斜、再沿竖直方向压扁到 0.42，形成斜视角（约 65°）。另外还有：中央核球的暖光与密集小星、沿旋臂的尘埃暗带（用 `destination-out` 挖出）、三颗会脉动的前景行星、流星、滚动视差。

> 说明：按要求上网找模板，但两次抓取都没拿到内容（搜索被重定向到无关结果、教程站返回 500）。因此按这类生成器的标准参数实现，没有凭空发明。

### 8.2 课程总览：顶部大字改为左侧固定栏，切换改成一屏一节

- **顶部大页头删除**。用户反馈「课程总览四个大字看不了」——它随滚动立刻消失。改为**固定在左侧的窄栏**：上面是页面名（现在是 h1，语义正确），下面五段依次排列，当前段高亮，点击可直接跳转。
- **切换改为一屏一节**：`html[data-snap="1"] { scroll-snap-type: y mandatory }`，每段 `min-height: calc(100dvh - 顶栏)`、`scroll-snap-align: start`、**`scroll-snap-stop: always`**（一次手势只翻一页，不会连跳），并且不再有「停在两段之间」的状态。实测五段逐段滚动的落点都精确在顶栏下方 `top: 62px`。
- **窄屏关闭吸附**：手机上内容常常比一屏高（实测某段 1554px），强制吸附会不断把人「弹回」段首，所以 ≤900px 时改为自由滚动。
- 翻书过渡随吸附一起柔化（透视从 `main` 移到每段自己的 `transform` 里）。

**一个隐藏的 bug**：把 `perspective` 放在 `main` 上会让 `position: fixed` 的子元素以 `main` 为参照，左侧固定栏因此被推到 1285px 处（屏幕外）。改成把透视写进每段的 `transform: perspective(1500px) rotateX(...)` 之后才恢复。

### 8.3 表格看不清：旧站样式污染了内容表格

暗色下表格出现「白字压白底」。根因是内容表格沿用了旧站的 `theory-table` 类名，而 `demos.css` 里正好有 `.theory-table tr:nth-child(even) td { background: #f8fafc }` —— 近白底配上暗色主题的近白字，等于看不见。

两处一起修：
1. **内容表格不再借用旧类名**，由 `prose.css` 的 `.table-wrap` 自己接管；
2. **`demos.css` 全部规则加上 `.demo-block` 前缀** —— 演示样式只在演示区生效，从结构上杜绝这类污染。

修后实测表格对比度：暗色 15.1:1、亮色 17.9:1（WCAG AAA 要求 7:1）。

### 8.4 全站文字对比度审计

按「把内容自己再审视一遍」的要求，写了一个页面内的对比度审计脚本（解析 `rgb()/rgba()/color(srgb …)`、逐层合成半透明背景、跳过渐变文字与渐变背景），跑了 **4 个页面 × 2 种主题**：

| 问题 | 修法 |
|---|---|
| 侧栏「当前章」的编号是**白字压浅金**，暗色下只有 **1.57:1** | 新增成对的徽标令牌 `--badge-bg / --badge-ink`，暗色用深墨压浅金、亮色用白压深金 |
| 次要文字 `--text-3` 在 3.3–3.9:1 之间（Tab 计数、章节编号、分区导航等） | 暗色提亮到 `#808896`、亮色压深到 `#5f6a73` |
| Tab 上的条目计数偏淡 | 改用 `--text-2` |

复测结果：**lesson / overview × 暗色 / 亮色，0 处低于 4.0:1**。

### 8.5 另一处静默失效

`initDeck()` 定义了但从未被调用 —— 我上一轮插入调用时用的锚点里含早已删除的 `initRails()`，替换静默失败。表现为左侧分区导航永远停在第一项。补上调用后，五段逐段滚动的跟随全部正确。

## 9. 动效默认开启 · 亮色银河改墨线星图

### 9.1 动效默认开启

上一版为了尊重系统偏好，默认「系统开了减少动效就关闭动画」，结果这台机器的系统偏好一直是关闭状态，用户看不到任何动效。按用户要求改为：

```
data-motion = (localStorage 里显式关过 ? 'off' : 'on')
```

即**默认一律开启**，系统偏好不再作为默认依据；顶栏的星芒开关随时可以关掉，选择会被记住。实测：清空 `localStorage` 后刷新，`data-motion = "on"`，银河逐帧在变（两帧画布哈希不同）。

### 9.2 亮色主题的银河改成「墨线星图」

在亮色下，原本用浅色星点（香槟/灰玉）画星，结果是几乎看不见的一层雾。改为**深墨画星**：星点用 `#4a3a1e / #333d3a / #2b3640` 三档墨色、按亮度分桶，核球用暖墨，读起来像印在纸上的星图 —— 这正好贴合「星图」这个设计方向，也让亮色下真正看得见结构。

## 10. 手感修正：鼠标跟手 + 总览页翻页不卡

### 10.1 鼠标延迟

原因很直接：**位移的 `transform` 上挂了 `0.16s` 的过渡**，指针位置被过渡插值，于是永远「追」着真实位置跑。

修法是把两件事拆开：

| 元素 | 负责 | 过渡 |
|---|---|---|
| `.cursor-wrap` | **在哪**（`translate3d`） | **无**（只有 opacity 淡入淡出） |
| `.cursor-arrow` | **什么状态**（缩放 / 歪头） | `0.12s` |

另外把位置从「每帧写两个 CSS 自定义属性」改成「直接写 `transform`」，少一次自定义属性解析。实测 `.cursor-wrap` 的 `transition-property` 只剩 `opacity`。

### 10.2 总览页翻页卡顿

原来用 CSS `scroll-snap-type: mandatory` + `scroll-snap-stop: always`，两个问题叠加：

1. 吸附动画由浏览器执行，而页面里有大面积**毛玻璃**（`backdrop-filter`），滚动时每帧都要重算背景模糊 → 吸附过程掉帧；
2. 不同设备的滚轮/触控板惯性差异很大，强制吸附容易把人卡在两段之间，或者一次手势连跳两页。

改为**自己接管 wheel**：
- 一次手势 → 只滚一页，用 `requestAnimationFrame` 做缓动补间（距离自适应 300–620ms，easeInOutCubic），滚动手势期间加锁，因此不会连跳；
- 事件目标若位于还有余量可滚的子元素里，就把控制权交还原生滚动；
- 关闭动效（顶栏星芒开关）时完全走原生滚动；
- 左栏分区导航的点击复用同一套补间，手感一致。

同时降低合成成本：翻页效果从 **3D 透视/旋转/缩放** 改成**位移 + 淡入**（大面积 `backdrop-filter` 叠加 3D 变换是逐帧重算的主因），去掉顶边的翻页阴影层，毛玻璃模糊半径 `20px → 14px`。

**实测**：补间期间帧间隔中位 **7.0ms**、P95 **7.8ms**、最大 **8.8ms**（约 143fps，无掉帧）；一次滚轮精确落在顶栏下方 `top: 62px`；反向滚动正常回到上一段；连续快速滑动两下只前进一页；章节页没有 `data-snap`，完全不受影响（实测自由滚动到 535px）。
