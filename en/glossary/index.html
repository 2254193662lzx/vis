Data & Encoding

TermDefinitionAppears in
DIKW PyramidA four-tier progression from Data to Information, Knowledge and Wisdom: raw observations become information once contextualized, knowledge once patterns emerge, and wisdom once decisions follow.1.2 数据定义
Stevens' Measurement ScalesFour attribute types ranked by which mathematical operations remain meaningful: nominal, ordinal, interval and ratio. The scale determines which visual channels and statistics are semantically valid — averaging nominal data is meaningless.1.3 数据属性
Visual ChannelsThe graphical variables that carry data attributes — position, length, area, angle, hue, luminance, shape. Mackinlay ranked them by perceptual accuracy: position and length suit quantitative data, hue suits categories, while area and lightness distort easily.1.3 数据属性
Data-Join (enter / update / exit)D3's declarative binding model: data without a matching element is enter (create), matched pairs are update (modify), and elements without data are exit (remove). It turns 'sync the view to the data' from imperative step-by-step work into a derivable difference operation.1.5 D3 数据选择器

Workflow & Layout

TermDefinitionAppears in
Card's Data-Flow ModelCard et al.'s reference model for visualization: raw data → data tables → visual structures → views, joined by data transformations, visual mappings and view renderings, with user interaction able to feed back into any stage.2.1 数据可视化流程
d3.rollup (multi-level aggregation)Groups an array by one or more keys while reducing each group (count, sum, …), returning a nested Map. It is the workhorse transform from raw records to a plottable aggregated table.2.2 数据分类树
Reingold-Tilford LayoutA classic tree-drawing algorithm: subtree extents are computed bottom-up, then coordinates assigned top-down so siblings never overlap, parents sit centered above their children, and the whole tree stays compact.2.3 树布局
Event DelegationBinding one listener on a parent and dispatching by event bubbling and target, instead of binding to every child. With nodes added and removed frequently this avoids listener leaks and repeated binding.2.4 树形列表渲染

Color

TermDefinitionAppears in
ColormapA function mapping numbers to colors, in three kinds: sequential (one hue light→dark for a one-directional magnitude), diverging (two hues around a neutral for deviation from a baseline), and categorical (unordered, discrete, for categories). Choosing the wrong kind makes data read as the wrong meaning.3.2 colormap 三类选择
CIE Lab Color SpaceA perceptually oriented space: L for lightness, a/b for the red–green and yellow–blue opponent axes. Euclidean distance in Lab approximates perceived difference, making it suitable for quantifying 'how different are these colors' — something sRGB cannot do.3.3 CIE Lab 色域图
Color Vision Deficiency (CVD)About 8% of men have some degree of red–green deficiency. Palettes that lean on strong red/green contrast collapse into one color for them, so good practice is never to rely on hue alone — add a lightness difference or a redundant cue such as shape or dash pattern.3.8 CVD 论文图测

Low-Dim & Contours

TermDefinitionAppears in
Cleveland's 45° InclinationCleveland's finding that people judge whether slopes are equal best when lines sit near 45°, where the perceptual threshold for slope difference is smallest. Adjusting the aspect ratio to bring the slopes of interest near 45° therefore makes differences easier to read.4.4 倾角感知
Marching SquaresAn algorithm extracting iso-lines from a regular grid: compare each cell's four corner values against the threshold to get one of 16 binary cases, then interpolate across cell edges using a lookup table. It underlies contour plots and terrain maps.4.5 等值线

Time

TermDefinitionAppears in
Calendar HeatmapVan Wijk and van Selow's representation of time data: lay out time hierarchically as year → month → week → day in a calendar grid, encoding each day's value as color. It turns periodicity into vertically aligned columns so the same day across years compares directly — something a line chart cannot do.5.3 日历热图
Archimedean SpiralMapping cyclic time onto a polar spiral: angle encodes position within the cycle and radius grows linearly with cycle count. Years visually meet end-to-end, periodic patterns align along the spiral, and the forward direction of time is preserved.5.4 周期时间可视化
StorylineTanahashi and Ma's visualization for event narratives: each entity runs along a horizontal timeline, and when entities interact, links appear and tracks shift. It expresses both how entities change over time and how they interact — a canonical dynamic-network time series.5.5 Storyline 时间线
Decomposition of Time AttributesTime is not one dimension but at least five attributes: instant, interval, duration, order and periodicity. Which attribute a chart foregrounds determines whether a line chart, heatmap or spiral is appropriate — decide the question before choosing the chart.5.1 时间属性
