How to use

Click a title to expand.

Open a chapter and walk through sections in order, switching to Demo to run it live on the page.

The sidebar lists all chapters plus the current chapter's sections; "Mark learned" records progress and updates the rings.

Ctrl/⌘ + K searches prose, key code and glossary across the whole site. The glossary gives bilingual definitions.

The build output is plain static files with D3 bundled locally — no network needed. Just run python -m http.server.

About this course

Click a title to expand.

Chen Wei, Introduction to Visualization; Mackinlay 1986 channel ranking; Stevens 1946 measurement scales; Cleveland 1984 45° inclination; Card 1999 data-flow model.

Case-centered: every concept is embedded in a real dataset case, with key points and a runnable demo.

Zero runtime dependencies: built into plain static HTML/CSS/JS, D3.js v7 bundled locally, no framework, no CDN.

Keyboard navigation, dark mode, focus mode, print-to-handout of the whole lecture, and respects prefers-reduced-motion.

Read data as charts, and charts back as data.

All 27 sections and 27 runnable demos are one click away.
