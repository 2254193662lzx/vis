使用方式

点击标题展开详情。

打开任一章节，按小节顺序讲解，随时切到「演示」在页面内实时运行。

侧栏可看到全站章节与本章小节，右上角「标记已学」记录进度，进度环自动更新。

Ctrl/⌘ + K 打开全站搜索，覆盖小节正文、关键代码与术语；术语表给出双语释义。

构建产物为纯静态文件，D3 已本地打包，无需联网；直接 python -m http.server 即可。

关于本课程

点击标题展开详情。

陈为《可视化导论》、Mackinlay 1986 视觉通道排序、Stevens 1946 测量尺度、Cleveland 1984 45° 倾角、Card 1999 数据流模型。

案例为中心：每个知识点都嵌入真实数据案例，配关键点解释与可运行演示。

零运行时依赖：构建期生成为纯静态 HTML/CSS/JS，D3.js v7 本地打包，无框架、无 CDN。

支持键盘导航、深色模式、专注模式、打印导出完整讲义，并遵循 prefers-reduced-motion。

把数据读成图，把图读回数据。

27 个小节、27 个可运行演示都在总览页等着。
